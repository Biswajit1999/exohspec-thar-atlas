# Changelog

## 0.3.0 — 2026-09-18

- Added a 24,000-injection detector-domain centroid recovery study using the 24
  published feature strengths and all four measured exposure durations.
- Compared fixed 120 s, fixed 180 s, longest-unsaturated, and pixelwise-HDR
  centroid strategies on identical seeded realizations.
- Rejected the predeclared strong-feature null: pixelwise HDR reduced RMSE by
  83.9% relative to fixed 180 s while preserving faint-feature performance.
- Added machine-readable evidence, a claims register, a limitations document,
  six tests, and Python 3.10/3.12/3.13 continuous integration.
- Updated GitHub Actions to supported runtimes and published the new study on
  the project website.

## 0.2.0 — 2026-09-10

- Published privacy-reviewed measured line candidates, visible NIST reference
  lines, wavelength-direction guidance, and expanded detector diagnostics.
